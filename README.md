# Google-Colab-ML

Machine Learning practical assignments and implementations created via Google Colab.

## Automated PDF Export
This repository includes an automated GitHub Action that converts pushed Jupyter Notebooks (`.ipynb`) into submission-ready PDFs with full code and outputs preserved.

### How to get your assignment PDF:
1. Save your completed notebook from Google Colab (**File > Save a copy in GitHub**).
2. GitHub Actions will automatically detect the updated `.ipynb` and convert it into a formatted PDF using headless Chromium.
3. Download the generated PDF:
   - **From Releases:** Go to the [Releases](https://github.com/jha-rishika/Google-Colab-ML/releases) section and download the latest assignment PDF.
   - **From Actions:** Go to the **Actions** tab, click on the latest workflow run, and download the `assignment-pdfs` artifact.
